FIFO-Based Seat Allocation

An advanced priority-based waiting list and dynamic seat management system.

ℹ️

Note: This webpage is only to understand what this system does from an analysis of the entire codebase. It serves as a visual representation of the underlying C application.

🎯

Problem Statement

Traditional seat booking systems often lack dynamic scaling and struggle with priority-based waitlist management without relying on heavy, resource-intensive frameworks.

💡

Reason to Develop

I recognized the need for a highly efficient, lightweight seat management system that runs on minimal hardware while supporting advanced features like VIP priority queuing for my semester project.

⚠️

Development Challenges

Implementing a priority queue that maintains FIFO order for standard users while accurately placing VIP users ahead was a significant algorithm challenge, alongside ensuring zero memory leaks during dynamic seat scaling.

✅

Provided Solution

A C-based, memory-safe system utilizing singly linked lists for the seating map and a priority-based linked list for the waiting queue, ensuring rapid allocation and robust file I/O operations.

👑

Priority Waitlist

VIP passengers are seamlessly prioritized in the queue, ensuring premium users receive immediate allocation when seats free up.

🔄

Dynamic Scaling

Add or remove seats at runtime without restarting. The system dynamically scales to accommodate varying vehicle or venue capacities.

💾

Persistent State

Robust file I/O operations ensure that all bookings and waitlists are saved securely to disk, preventing data loss between sessions.

📊

Intelligent Reporting

Search algorithms to quickly locate passengers and generate real-time occupancy metrics and CSV exports for external analysis.
